# 每日表达记录与工作台问题折叠

目标：个人工作台增加GitHub式年度热力图，展示每日已保存录音次数；工作台问题默认仅展示标题，点击展开，练习详情仍默认展开第一条。

口径：按北京时间、录音创建时间统计，重练每轮计入，草稿/感悟/分析任务不计入，AI分析失败的已保存录音仍计入。仅统计本人当前未删除的练习；删除后同步移除。只表示记录数量，不代表能力、打卡或训练效果。

- [x] Store按日聚合、日期详情与账号隔离，workspace返回聚合及北京时间today。
- [x] 纯日期工具覆盖北京时间边界、闰年、年度周网格和未来日期；单元测试先验证。
- [x] ActivityHeatmap年度切换、月份/星期、颜色图例、真实次数提示、点击/日期输入查看记录；手机内滚动不影响整页，支持键盘导航。查询状态留在URL，加载/空/错误状态明确。
- [x] 工作台问题用原生details默认收起，展开后保留原文/问题/建议、来源及综合重练入口；练习详情折叠规则不变。
- [x] 浏览器验证年份/日期选择、每日记录、删除同步、问题折叠、手机布局；类型检查/单元/构建/Hallmark与真实模型兼容测试。
