# 六种场景的表达练习

新流程：个人工作台的新建入口 → 选择六种表达场景之一 → 确认并创建练习 → 输入/语音输入自选主题 → 对照框架录音 → 原有分析、重练和对比。选择阶段不创建空记录；选择写入URL，可刷新恢复。

场景目录以src/lib/scenarios.ts为单一来源，包含用户给出的六个场景、步骤、示例及适用提醒。录音页以SceneGuide展示，示例可展开。历史记录标识场景，重练沿用。场景和五维评价不同：框架用于组织思路，评价仍归入抓重点、排顺序、展开、衔接与恢复、口头禅与语气垫词。AI不强制逐步照念；示例只展示给用户，不传入模型，避免污染实际转写。

持久化：practices增量新增scenario列，旧记录为空，不推测分类；保留原有主题、录音与分析。新建API必须接受六个有效场景ID之一，缺失或未知值返回400。场景在创建时确定，已有练习及重练不随意切换。

验证重点：旧DB迁移、六种场景持久化、有效输入校验、选择前不创建记录、刷新恢复、移动端无溢出、录音框架可见、真实模型分析及完整旧流程回归。
