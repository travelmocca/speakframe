# 表达练习网站 PRD

- 版本：V0.1
- 日期：2026-10-30
- 状态：需求草案
- 范围：个人口头表达的记录、AI复盘、针对性重练及前后对比。
- 已确认模型：第一版直接使用千问 Omni（当前已测试 `qwen3.8-omni-flash`）进行录音转写、分析与评价。

## 1. 产品定位

面向希望改善口头表达的成年人，帮助用户发现表达中的具体问题，针对一个问题重新表达，并回看两次表现。长期愿景是帮助用户减少对完整稿件的依赖，围绕要点清楚、连贯地表达；本版不评价长期训练效果。

## 2. 核心流程

**用户自行选定表达主题 → 录音表达 → 转写与AI分析 → 回看具体问题 → 选定一个问题重练 → 比较两次表现。**

本版不提供题库或自动出题。新建时只需表达主题，不再单独填写表达目标。主题可手动输入，或录制最长30秒的语音，由千问转成文字并自动保存；用户可修改文字。主题转写的临时音频处理后清理，不作为正式练习记录保存。

## 3. 核心功能

| 编号 | 功能 | 需求 |
| --- | --- | --- |
| FR-01 | 新建练习 | 系统必须支持用户填写或语音输入自选主题，开始、停止并回听录音。 |
| FR-02 | 记录与转写 | 系统必须保存原始录音及其转写文本；用户可从记录列表重新打开练习，回听并查看转写。 |
| FR-03 | AI分析与评价 | 系统必须基于表达主题及表达内容，按统一问题框架给出分析与评价。每个问题必须包含分类、具体原话或时间位置、对理解的影响和可执行的改进动作；证据不足时必须说明，不能强行判定存在问题。 |
| FR-04 | 针对性重练 | 用户必须能从已发现的问题中选定一个后重新录音；系统必须保存重练录音、转写，并关联原始表达及选定问题。 |
| FR-05 | 前后对比 | 系统必须支持回看两次录音和文本，由AI围绕选定问题给出有依据的变化说明，包括改善、仍存在的问题或无法判断；不能预设重练必然更好。 |
| FR-06 | 删除 | 用户必须能删除整组练习，删除前确认。删除范围包括原始表达、重练、录音、转写、分析与对比结果；不能仅隐藏列表项。 |
| FR-07 | 注册与登录 | 用户使用手机号和密码注册、登录，不使用验证码；手机号必须唯一，密码必须以安全哈希保存。每位用户只能访问和删除自己的练习数据。手机号未验证，不代表已确认号码归属；密码找回方式待定。 |

### 统一问题框架

以下五个维度已确认为本版统一问题框架；具体判定细则仍需在模型验证中明确，不代表框架已经过完整效果验证：

| 维度 | 观察方向 |
| --- | --- |
| 抓重点 | 核心意思是否明确，是否围绕表达主题展开。 |
| 排顺序 | 内容顺序及观点、理由之间的关系是否清楚。 |
| 展开内容 | 是否提供必要的解释、理由或例子；根据任务判断，不要求每次都有例子。 |
| 衔接与恢复 | 内容是否衔接，是否反复绕圈，卡住后能否继续主线。 |
| 口头禅与语气垫词 | 是否过多、重复使用“嗯”“啊”“然后”“就是”等口头禅或语气垫词，影响表达的简洁与连贯。结合具体语境判断，不将正常、有实际含义的用法判为问题。 |

框架应参考成熟表达方法和研究依据，保留来源及适用边界。AI反馈必须采用同一套分类标准，并记录使用的框架版本。口头禅与语气垫词的分析必须引用具体片段，并给出删减重复、用自然停顿替代等改进动作；转写若省略了相关词语，必须说明证据不足，不能据此判定没有问题。不能仅凭语气词或停顿数量判定表达能力；缺少音频分析能力时，不得声称已评价语速、停顿或声音表现。

## 4. 页面与数据

- **个人工作台**：包含新建练习、历史表达及当前问题分析。历史展示主题、时间、版本数与处理状态，支持进入及删除。当前问题只汇总各组最新一次已完成分析的表达；最新版本尚未完成分析时暂不计入，不回退旧版本。支持按五个维度筛选，并从具体反馈进入对应问题重练；问题条数不代表能力评分。
- **注册与登录**：手机号加密码，不使用验证码；练习记录归属于登录用户。
- **练习详情**：包含表达主题、录音、转写、问题列表、重练入口与前后对比。
- 页面结构已确认：登录／注册、个人工作台、练习详情，共三个页面类型；重练与比较在工作台内完成。
- 每组练习保存：主题、原始表达、目标问题、重练记录、AI分析、对比结果及创建时间。
- **设计假设**：允许多次重练，每次保留记录并明确与哪一次表达比较；具体交互可在设计时简化。

## 5. 异常与边界

- 无麦克风权限或未获得有效录音时，必须明确提示，不能显示录制成功。
- 转写或AI分析失败时，必须保留已成功保存的录音，显示失败状态并支持重试。
- AI必须以用户实际表达为依据，不得把自行补充的内容当作用户原话或用改写答案替代问题分析。
- “前后对比”只描述本次两段表达的差异，不等同于整体能力提升或长期训练效果评价。

## 6. 本版不包含

- 题库、自动出题、课程及训练计划。
- 难度递进、训练周期、打卡机制。
- 长期效果评价、能力等级、综合评分及排行榜。

## 7. 简要验收

| 用例 | 覆盖需求 | 操作与预期 | 验收证据 |
| --- | --- | --- | --- |
| 自选内容与回看 | FR-01、02 | 填写或语音输入主题，完成录音；离开后重新打开，能播放同一录音并看到对应转写。 | 操作录屏及记录数据核对。 |
| 问题反馈 | FR-03 | 用含明确表达问题的样本分析；反馈按框架分类、关联原话或位置并给出改进动作；无充分证据的项目不强行判定。 | 样本、分析结果及人工核对记录。 |
| 重练与比较 | FR-04、05 | 选定问题并重练；两次录音、文本及关联关系完整，对比围绕该问题并提供两段内容的依据。 | 操作录屏、关联数据及对比人工核对记录。 |
| 删除 | FR-06 | 确认删除一组含重练的练习；列表不可见、原资源不可访问、关联数据与文件已删除。 | 界面及存储核验记录。 |
| 账号与隔离 | FR-07 | 使用手机号和密码注册、登录，无验证码步骤；重复手机号不能注册；其他用户不能访问或删除本人的录音、文本及分析结果。 | 操作记录及接口权限核验记录。 |
| 异常恢复 | FR-01、02、03 | 拒绝麦克风权限、模拟转写或分析失败；提示准确，已保存录音不丢失，失败任务可重试。 | 错误界面及重试结果。 |

验收记录需包含用例、结果、证据位置、验证人、日期与例外说明；以上用例通过后方可确认本版验收。

## 8. 待定事项

- 统一问题框架的具体判定细则与方法来源；五个维度已确定。
- 录音技术方案与转写纠错方式；AI模型已确定，首版直接使用Omni，保留已发现的计数和时间定位限制。
- 密码找回方式、存储位置、第三方服务的数据留存与删除机制。

以上为待定实现事项，不视为已确认产品功能。录音、转写和分析涉及哪些第三方服务，应在用户录音前提供简明说明。
