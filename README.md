# 表达练习

一个可在本机运行的口头表达练习网站。自选内容录音，使用千问 Omni 转写并按五个维度分析，选一个问题重练，再比较两次表现。

## 使用

当前机器已配置百炼密钥，访问：<http://127.0.0.1:3118>。首次使用自行注册手机号和密码，无需验证码。

服务未运行时，在项目目录执行：

```bash
npm start
```

此命令同时启动正式网站和分析worker。首次启动或修改代码后先执行：

```bash
npm ci
npm run build
npm start
```

开发模式使用 `npm run dev`，也同时启动worker。修改worker代码后重启此命令，避免后台仍运行旧代码。

## 配置

依赖Node.js 22及FFmpeg（含ffprobe）；当前机器均已具备。新机器先安装这些依赖，再将 `.env.example` 复制为 `.env.local` 并填写：

```dotenv
DASHSCOPE_API_KEY=你的百炼密钥
DASHSCOPE_BASE_URL=你的业务空间OpenAI兼容地址
QWEN_MODEL=qwen3.8-omni-flash
APP_DATA_DIR=var
PORT=3118
```

密钥与调用地址必须属于同一地域。密钥只在服务端使用，不能加 `NEXT_PUBLIC_` 前缀。现有导出CSV不作为应用运行时依赖，不要提交到Git。

默认仅监听本机。如果将来部署到服务器，需要持久磁盘、常驻Node和worker、HTTPS反向代理，并将`APP_ORIGIN`设为实际站点来源；不要直接放入临时磁盘的函数平台。

## 已实现

- 手机号密码注册、登录、退出；密码哈希、会话过期、接口归属校验。
- 新建前选择六种表达场景之一；录音和重练时展示对应框架、提醒与示例，AI结合场景分析。
- 自选主题（支持语音转文字并自动保存），浏览器录音、回听、重录，原始音频私有保存。
- 千问 Omni 直接听音并保留垫词转写，输出重点、顺序、展开、衔接、口头禅五维观察及具体问题。
- 个人工作台汇集历史表达及各组最新版本问题，支持维度筛选与直达重练。
- 选定一个问题重练，保留每个版本；按原始来源进行前后对比。
- 分析后台运行，失败可手动重试；刷新和服务重启后保留记录。
- 删除整组练习及其录音、转写、分析、比较；正在处理的任务不能重新写回。
- 未保存录音离开提醒，麦克风权限拒绝、损坏音频、模型异常等错误提示。

未保存录音可在当前页面会话的站内后退／前进后恢复；刷新或关闭页面仍会提示，只有点击保存后的录音才持久写入服务端。

录音最长10分钟、50MB。上传后实际解码校验；模型输入使用16kHz单声道96kbps MP3，控制编码后的Base64小于10MB，不裁静音、不顺滑垫词；原始上传文件完整保留。

## 数据与备份

数据库在`var/app.sqlite`，录音在`var/audio`；目录仅当前系统用户可访问。`var/tmp`为转换临时文件。用`APP_DATA_DIR`可更换位置。

备份时先停止网站与worker，然后复制整个`var`目录（包含SQLite可能存在的WAL文件），恢复也需停止服务。保留同一套数据库和音频，不能只备份其中一个。模型服务商的数据留存不由本地删除接口控制。

## 验证

```bash
npm run typecheck
npm test
TEST_BASE_URL=http://127.0.0.1:3118 npm run test:e2e
npm run build
```

E2E需先运行网站与worker，使用本机Chrome。主流程通过浏览器MediaRecorder录制合成音频作为虚拟麦克风输入，并调用真实百炼模型，会产生API用量；没有将固定分析结果作为模型返回。麦克风拒绝场景单独模拟权限错误。

验收证据在`outputs/uat`，包括页面截图和服务重启前后校验。独立代码审查的修复与测试记录见该目录验收报告。

## 已知边界

- 模型可能漏识别、误判或生成无法匹配的引用；未核验引用会提示，比较无法核验时降为“无法判断”。
- 不使用模型生成的精确时间戳驱动定位；录音可自行拖动回听。
- 没有验证码、密码自助找回、课程、难度递进、周期或能力总分。
- 桌面Chrome是完整录音链路的已验证浏览器；其他引擎和真实手机的验证范围以验收报告为准。
- 本机尝试的Playwright WebKit被冻结版本与当前驱动不匹配（`Unknown setting: PushAPIEnabled`），未计入通过结果。
