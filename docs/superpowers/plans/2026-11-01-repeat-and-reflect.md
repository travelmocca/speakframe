# 综合重练与退出感悟 Implementation Plan

> 执行方式：使用 executing-plans，逐项实现并验收，保留已有数据与路由。

**Goal:** 同一主题可多次综合重练，每轮自动与相邻上一轮比较；退出前可用文字或语音保存感悟。

**Architecture:** 沿用SQLite、异步worker及千问Omni。每个新版本由服务端关联紧邻上一版本，完成分析后原子创建对比任务；比较覆盖五个问题维度且逐条核验原话。感悟独立追加存储，语音转写用临时文件并清理。

**Tech Stack:** Next.js/React/TypeScript、better-sqlite3、FFmpeg、MediaRecorder、Qwen Omni、Vitest、Playwright。

- [x] 数据及测试：Store.addAttempt统一关联上一轮，禁止跨组/越版本重练及未完成分析时叠加；completeJob自动排队比较，requestComparison去重；感悟归属、追加、删除级联。
- [x] 对比结构：analysis-schema扩展逐维变化（有改善/仍需改进/无法判断），不预设进步；核验两轮原话，兼容历史单问题对比；worker始终覆盖所有问题和五维观察。
- [x] 感悟接口：POST reflections保存文字，reflection-voice鉴权、限时2分钟、忠实转写、不润色、不生成建议，临时音频finally清理。
- [x] 前端：移除单问题重练按钮和目标选择；每轮完成可再次练习，自动展示与上一轮对比；版本/录音/所有问题回看；保留草稿与切换保护。工作台入口改为综合重练。
- [x] 退出：新增退出练习入口；可选填感悟，复用语音输入和实时波形；保存并退出/不记录直接退出/继续练习；录音或未保存草稿先处理，退出不丢失感悟；历史感悟可回看。
- [x] 验收：类型检查、单元、生产构建、Hallmark检查；真实模型浏览器完成至少3轮表达及2次自动对比，语音感悟、文字保存、刷新回看、归属与整组删除；明确模拟麦克风及受控反馈的边界。

假设：每轮对比紧邻上一轮，不保证每轮均改善；感悟可不填，填写则每次追加一条。旧单问题分析与比较保留供回看，新重练只使用综合模式。
